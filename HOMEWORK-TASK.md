### Практическое задание

#### Задание 1. Система управления проектами

Создайте типы:
```ts
Project
Participant
Task
UserSettings
```
При проектировании используйте следующие требования:
- идентификаторы и даты создания должны быть readonly;
- у проекта должен быть список задач только для чтения (readonly Task[]);
- настройки пользователя должны храниться через Record;
- создайте отдельные типы:
-- CreateProjectCommand;
-- UpdateProjectCommand.

Напишите функцию:
```ts
updateProject(
  project: Project,
  command: UpdateProjectCommand
): Project
```
Функция должна:
- не изменять исходный объект;
- возвращать новый объект;
- изменять только переданные поля.

#### Задание 2. Мини-CRM

Создайте модель клиента:
```ts
Customer
```
Требования:
- id — readonly;
- createdAt — readonly;
- список адресов должен иметь тип readonly Address[];
- дополнительные пользовательские поля должны храниться в словаре
[key: string]: unknown

Создайте типы:
```ts
CreateCustomerCommand
UpdateCustomerCommand
```
Напишите функцию
```ts
updateCustomer(
  customer: Customer,
  command: UpdateCustomerCommand
): Customer
```
Функция должна:
- проверять совпадение id;
- возвращать новый объект;
- не изменять исходный объект.

#### Задание 3. Настройки уведомлений

Создайте тип
```ts
NotificationType =
  | "email"
  | "sms"
  | "push"
  | "telegram";
```
Используя Record, создайте тип NotificationSettings в котором для каждого типа уведомлений хранится значение boolean.

Создайте объект настроек и попробуйте:
- удалить один из обязательных ключей;
- добавить несуществующий ключ.

Изучите сообщения TypeScript и объясните, почему появляются ошибки.
