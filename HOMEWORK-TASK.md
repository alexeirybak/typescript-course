### Практическое задание

#### Задание 1

Создайте дискриминируемое объединение `Notification` для трёх типов уведомлений:

* `email`;
* `sms`;
* `push`.

У каждого уведомления должны быть общие поля:

* `id`;
* `createdAt`.

При этом каждый вариант должен иметь собственные поля.

Например:

* `email` — `email`, `subject`;
* `sms` — `phone`;
* `push` — `deviceId`.

Затем:

1. Напишите функцию `formatNotification`, использующую `switch` по полю `type`.
2. Добавьте `assertNever` для проверки полноты обработки.
3. Создайте массив уведомлений и выведите описание каждого из них.
---

#### Задание 2

Дан массив неизвестных данных:

```ts
const values: unknown[] = [
  { id: 1, name: "Анна" },
  { id: "2", name: "Иван" },
  null,
  "Hello",
  { id: 3, name: "Мария" },
];
```

Создайте тип:

```ts
type User = {
  id: number;
  name: string;
};
```

Затем:

1. Напишите пользовательский type guard `isUser`.
2. Отфильтруйте массив до `User[]` с помощью `filter`.
3. Выведите имена всех найденных пользователей.
4. Напишите assertion function `assertIsUser` и продемонстрируйте её использование на одном объекте.
